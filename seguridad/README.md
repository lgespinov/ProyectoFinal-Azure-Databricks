# Seguridad - Azure Databricks

Esta carpeta contiene los scripts de seguridad
para gestionar los permisos mediante Unity Catalog.

Catalogo: proyectofinal_dev

Grupos:
- grp_ingenieria_datos
- grp_consulta_gold

Politicas de acceso:
- Bronze: lectura para ingenieria de datos.
- Silver: lectura para ingenieria de datos.
- Gold: lectura para consulta analitica.

Los permisos se implementaran mediante
sentencias GRANT en Databricks SQL.
